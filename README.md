# 2048 Clone (Python)

A Python implementation of the classic 2048 puzzle game.

## Requirements
- Python 3
- Tkinter

## How to Run
1. Install Python 3.
2. Clone or download this repository.
3. Open a terminal in the project directory.
4. Run the game:

   ```bash
   python puzzle.py
   ```

## How to Play
- Use the arrow keys to move tiles.
- Matching tiles merge into a tile with their combined value.
- Press **B** to undo a move.
- Press **Escape** to quit the game.

## Project Files
- `puzzle.py` — game entry point and interface.
- `logic.py` — game logic.
- `constants.py` — game constants.
